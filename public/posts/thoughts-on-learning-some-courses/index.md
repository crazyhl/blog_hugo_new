# 关于学习一些课程的思考


这几年在网上买了很多可能，一般都是几十或者几百块，这些课程，对于我来说可以很明白的区分，对我有用，对我些许有用，以及不太适合我。但是今年在34月份的时候，因为疫情在家工作，我居然脑子抽了花了上万买了一个架构课。这是一个让我很迷茫的课程，对我有用么，有，对我没用么，也可以说没有。学习到了东西，但是很多东西却在实际工作中用不上，或者说没有机会场景用。这就让我有了今年的这个思考。

其实这个思考早就有了，只不过是一直拖到了现在才去写，一是害怕当时思考的太简单，二是觉得可能是我自己的问题明明是没有学会学懂缺怪罪到课程对我意义不大。但是经过了差不多 2 个月之后，我可以放心的动手写这个了。因为我觉得现在的思考，有助于以后的复盘并且也没有那么盲目了。

首先啊，任何课程对于任何人都是有帮助的，但是帮助的程度都是要依靠个人的。因为每个人的程度并不同所以每个人的吸收理解都会不同，就比如跟投资一样，一个基金经理会给出预期，但是实际上还是需要看真正运行一样。课程就是给出了预期，实际运行就是我们每个人的学习情况，以及每个人的真实能力值。如果刚好匹配就会学的很爽，体会很深。

如果跟课程的匹配程度不那么高的话，可能就会像我一样学习来有些吃力，外加挫败感。其实这种感受会让很会丧很颓废，甚至有时候会让我产生是我的脑子不行，可能不太适合程序员的工作。应该回到老家干个面馆，实现我多年的梦想。哈哈哈。

但是事后仔细想想呢，其实也并不是我不太行，是我没接触过东西，所以就很难深入的思考。外加我有个个人的毛病就是遇到一些东西，总是先用自己瞬间的想法去回答。并没有深入的思考后在去回答。

这两个问题，第一个没办法解决，等待工作遇到，或者自己想办法创造场景去解决。第一个既然不那么容易解决，那么就优化第二点，以后当遇到问题点的时候，就不要那么盲目，而是冷静下来，仔细思考。

其实还有另一个思考，市面上所谓的各种企业级，中心的逻辑并没有什么更好的方案，企业级就是兜底兜底兜底，减少错误减少失败。一开始我是很不屑的。但是现在我理解的可能更好一点了。其实项目大了就是要稳，稳中求进的第一个字也是稳。

所以，这个就跟上面的思考一样，要冷静下来，多花点时间思考才行。

最后，现在市面上的课程太多了，选择一个跟自己匹配的还是有些难的，要自己对比选择一个最合适的才是好的。步子迈的大了，容易扯到蛋。
