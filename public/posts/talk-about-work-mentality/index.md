# 说说聊聊工作心态以及私活还有兼职


最近几周非常的疲劳，自己事后想想其实是我自己的问题，我不是很擅长处理工作内容，当有一些事情堆积起来的时候，我就会不自觉地紧张。哪怕事情已经分解好了，每天的工作量也都定好了。但是依然还是会不自觉的去思考以后的事情。总是想把事情赶紧都弄完了，然后无事一身轻。

这样就伴随产生了一些让我更烦恼的副作用。虽然每天的工作量都能保证完成，但是因为过多的无用思考，会导致自己工作效率降低，bug 产生的概率升高，以及让自己身心疲劳。如何解决呢？还得在分析分析，以及跟我媳妇唠唠可能才会有方案。

然后就说说私活以及兼职，这个问题呢，是前几天跟以前的同事聊起来的。对于我自己来说我是十分抗拒私活以及兼职的。为什么呢？因为我更想在私人时间自己控制。所以程序员7年多来，我只有在14年做过一个30分钟的小功能，最后这个功能还没收钱。哪怕在业余时间我也是写代码，我也不想去兼职或者私活，更深层次的原因依然还是上面提到的，会让我压力太大了。

所以说，目前亟需既觉得还是自己的心态问题。另外昨天还看到小团团停播了，每个人都有各自的烦恼，一点点解决吧。我都这个年龄了，快些解决可能还能让自己更快的进步一些。得努力赚钱，让娃有个好生活呢。
