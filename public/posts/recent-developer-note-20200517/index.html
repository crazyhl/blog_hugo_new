之前迁移到香港服务器之后，图片原本整的是本地存储。后来拉数据就给 jenkins 干崩了。今天优化了一波超时时间，以及拉取 git 的层级。

然后把图片上传到 github，这样 git 那边压力就完全减少了了。

还写了个上传 github 的插件，给 typora 用。现在博客算是没啥大问题了
